# name2win (Name to Windows)

**Version 2.0.0 (2026-10-16)**

Windows環境でファイル名として使用できない文字や、Zip解凍・古のWin32アプリ（MangaMeeya等）でのファイル操作時にトラブルの原因となる文字をクレンジングし、CP932（Shift_JIS）完全準拠の安全なファイル名に一括置換するC#製CLIツールです。
DiscordやPatreonなどからダウンロードしたファイルのファイル名整理・リネームに最適です。

## 特徴
* Windowsで使用不可の文字（`\ / : * ? " < > |`）を全角へ変換
* 波ダッシュ（`〜`）から全角チルダ（`～`）への統一
* ラテン文字のダイアクリティカルマーク（`é` → `e` など）の除去（※日本語の濁点・半濁点は保護）
* 丸数字の標準化（❶→①、㉑→(21) 等）
* **CP932非対応のかな救出**: ひらがなの `ゔ` (`U+3094`)・小書き `ゕ` `ゖ`、およびカタカナの `ヷ` `ヸ` `ヹ` `ヺ` を、CP932対応の `ヴ` `ヵ` `ヶ` `ヴァ` `ヴィ` `ヴェ` `ヴォ` へ自動変換
* **記号ファミリー集約**: 三角（`🔺` `▶` `◀` `▷` `◁` 等→`▲` `△` `▼` `▽`）、ダイヤ（`🔶` `🔷` `🔸` `🔹`→`◆` `◇`）、丸（`🔴` `🔵` `⚫` `⚪`→`●` `○`）、星（`☆` `✨` `⭐` `🌟`→`★`）、音符（`🎵` `🎶` `🎼` `♩` `♫` `♬`→`♪`）
* **古のWin32アプリ救済 (MangaMeeya対応)**:
  Unicode標準のハート（`♥`/`♡`）はShift_JIS非対応のため、MangaMeeya等のANSI Win32アプリではファイルを開けません。そのため、ハート系絵文字およびUnicodeハート（`♥`）は **Shift_JIS外字黒ハート（`\uE0A5` / `0xF0E6`）** へ、Unicode白ハート（`♡`）は **Shift_JIS外字白ハート（`\uE006` / `0xF046`）** へ自動変換し、MangaMeeyaで正常に開けるファイル名にします。
* **文字コード診断モード (`-c` / `--check`)**: 指定した文字列やファイル名を1文字ずつ解析し、`Unicode` / `Shift-JIS (CP932)` / `Win32判定` / `変換結果` を表形式でコンソールに出力
* **外部対応表サポート**: `name2win.mapping.txt`（または `.tsv`）による自由なカスタム置換（中国語の漢字 ➔ 日本語/カタカナ等の1対多置換、特定絵文字の個別置換など）
* Shift_JIS（CP932）往復検証による非対応文字・絵文字の厳密な単一「■」へのフォールバック
* 重複ファイル名の連番付与、およびMD5ハッシュ比較による完全一致ファイルの自動削除
* 変更箇所の色分け表示（変更前の該当文字: 赤 / 変更後の該当文字: 黄）

## コンパイル方法
Windows環境に標準搭載されているC#コンパイラ（`.NET Framework csc.exe`）でコンパイル可能です。
```cmd
csc name2win.cs
```

> [!NOTE]
> 本ツールは「Windows標準環境のみで自己ビルドできる手軽さ」およびセキュリティの観点から、exe の配布は行っていません。上記の手順でご自身の環境でビルドしてください。

## 文字コード診断モード (`-c` / `--check`)
ファイルが開けない原因文字を即座に特定するためのデバッグ・診断機能です。文字列またはファイルパスを指定すると、1文字ずつCP932互換性を診断して表形式で出力します（ファイル自体のリネームは行いません）。

```cmd
name2win.exe -c "テスト♬♥♡ゔ▶◀.zip"
```

## 注意事項
* **色分け表示と背景色**: 変更後の文字は黄色で表示されます。黒背景のターミナル（コマンドプロンプト / PowerShell / Windows Terminal の既定）を想定しているため、白背景のテーマでは黄色が見づらい場合があります。
* **事前確認の推奨**: 実際にリネームする前に、`-t`（テスト実行）オプションで変更内容を確認することをおすすめします。

## 外部対応表（name2win.mapping.txt）によるカスタマイズ

`name2win.exe` と同じフォルダー、またはコマンドを実行するフォルダーに `name2win.mapping.txt`（または `.tsv`）を配置すると、起動時に自動で読み込まれ、最優先で置換が適用されます。

* **書式**: `変換元[Tabまたは=または,]変換先`
* **コメント**: `#` または `//` で始まる行は無視されます。
* **1文字 ➔ 複数文字の置換に対応**:
  中国語（簡体字・繁体字）などのShift_JIS外漢字を、日本語の漢字やカタカナに展開できます。

```text
# 例1: 中国語漢字の日本語化（1対多置換）
酱=ちゃん
哔=ピー
哒=ダ
喵=ミャオ

# 例2: 絵文字の個別カスタマイズ
💛=
🍳=料理
```

## 古のWin32アプリがファイル名として読み込める文字リスト（仕様）

MangaMeeyaなどの古のWin32アプリ（内部で `CreateFileA` / `FindFirstFileA` 等のANSI APIを使用するアプリ）がファイル名として読み込める文字は、**「Windows-31J（CP932 / 拡張Shift-JIS）にコードポイントが存在する文字」と完全に一致**します。
CP932に存在しないUnicode文字は、OSのAPI変換時にすべて `0x3F`（半角の `?`＝ワイルドカード予約文字）に化けるため、ファイルオープン時にエラーになります。

## なぜ C# 5.0 を採用したのか？

本ツールは最新のC#言語仕様ではなく、あえて C# 5.0 で記述されています。これには実務上の強力な理由があります。

- **開発環境（IDE）の追加インストールが一切不要**
  Windows 11 には標準で `.NET Framework` とコンパイラ（`csc.exe`）が内蔵されています。Visual Studio などをインストールする必要はありません。
- **厳格な職場環境への適応**
  「指定されたアプリ・ツール以外はインストール禁止」という厳しいセキュリティ環境であっても、ソースコード（テキスト）さえ持ち込めれば動作させることができます。印刷物からメモ帳に打ち込むだけでも、Excel VBAマクロを作成するような手軽な感覚でコンパイル・導入が可能です。

- **v2.0.0**:
  - **文字コード診断モード (`-c` / `--check`) の追加**: 指定した文字列やファイル名を1文字ずつ解析し、Unicode・Shift-JIS(CP932)・Win32互換性判定・変換結果を一覧表で出力するデバッグ機能を実装。
  - **macOSダッシュ・ハイフン・JIS不一致記号の完全網羅**: 全13種のUnicodeハイフン・ダッシュ・マイナス類の半角 `-` 統一、波線 `〰` (`U+3030`) の `～` 化、および JIS/CP932 マッピング不一致記号（`‖`➔`∥`, `¢`➔`￠`, `£`➔`￡`, `¬`➔`￢`）の救出を追加。
  - **西欧合字・ストローク付き文字の展開 & 康熙部首の標準漢字救出**: NFDで分解されない西欧文字（`ß`➔`ss`, `æ`➔`ae`, `ø`➔`o` 等）のASCII展開、およびmacOS/PDF由来の康熙部首（`U+2E80`〜`U+2FD5`）を標準JIS漢字へ正規化する処理を追加。
